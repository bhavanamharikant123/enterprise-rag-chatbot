
# Enterprise RAG Chatbot

## Project Title

Production-Ready Enterprise Document Intelligence Platform

## Overview

Enterprise RAG Chatbot is an AI-powered document question-answering
application that allows users to upload enterprise documents
and ask questions using natural language.

The application retrieves relevant information from uploaded
documents and generates context-grounded answers using an LLM.

## Key Features

- Multiple PDF document uploads
- Document text extraction
- Intelligent document chunking
- Embedding generation
- ChromaDB vector storage
- Hybrid retrieval using BM25 and vector search
- Reciprocal Rank Fusion
- Cross-encoder reranking
- LLM-powered answer generation
- Conversational memory
- Source citations
- Real-time response streaming
- RAG evaluation
